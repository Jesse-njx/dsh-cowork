The problem

Your agent can’t open a spreadsheet.

DSH’s read is UTF-8 text only. An xlsx is binary — ask your agent for a cell value and it stares at bytes.

sample.xlsx
PK\x03\x04\x14\x00\x06\x00\x08\x00… \xC3\xA9\xBD… (binary)
What it is

Native document tools, inside DSH.

doc_read
Pages, rows, slides, cells — windowed, never a wall of text.
doc_write
Create and edit xlsx + ipynb by stable address.
Formats
xlsx · pdf · docx · pptx · ipynb in one consistent tool.
Caps
Every read is bounded; truncation is never silent.
The read → write loop

Cell refs for spreadsheets, shape ids for slides — addresses line numbers can’t give a binary file.

Safe by default

Reads are bounded. Writes are guarded.

Zip-bomb caps on every archive
Macro formats rejected outright
Read-only mode blocks all writes
Hash-checked, atomic edits
Never emits xlsm / docm / pptm
Truncation always says so
